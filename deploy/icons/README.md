# ZimaOS app icons

The icons ZimaOS shows for the three apps (the `icon:` line in each
`deploy/zimaos-*.yaml`, loaded from GitHub's raw URL on `main`):

| File | App | Mascot |
|---|---|---|
| `zimaos-home-tools.png` | Home Tools | purple blob with a roof (the Home Tools mascot, decision #62) |
| `zimaos-https.png` | Home Tools HTTPS (Caddy) | green blob holding a padlock |
| `zimaos-proxy.png` | Home Tools Docker access (socket proxy) | blue blob holding a shield |

512 × 512 PNGs: the blob (same shape code as avatars, seeded from the app's
title) on the brand's grid tile. `https.png` is the older tile icon.
